¿Porqué estudiar esta
especialización?
Implementa dos agentes IA especializados
en frontend y backend respectivamente,
para la creación de software a partir de
requerimientos, una arquitectura y un
lenguaje especificados
Frontend diseñado e implementado con IA
Convierte requerimientos de software en
interfaces funcionales en un lenguaje
elegido, empleando Figma AI para el diseño y
Claude para el código.
Backend implementado con IA
Implementa el backend completo para el
proyecto con Claude Code, a partir de los
requerimientos funcionales, un modelo
arquitectónico y un lenguaje elegidos.
Backend con un motor IA LLM
El backend incorpora una IA LLM mediante
API para la atención de solicitudes de usuario
en lenguaje natural que requieran la creación
dinámica de consultas SQL (a medida).
Agentes IA orquestados para frontend y
backend
Implementa con Claude Code una granja de
IAs basada en dos agentes, que crean
frontend y backend a partir de
requerimientos, arquitectura y lenguaje
especificados.

   Malla Curricular
   I. Frontend Engineering potenciado con IA
   (AI-Augmented)
1. Introducción al desarrollo potenciado con
   IA (AI-Augmented)
   • Conceptos generales AI, Gen-AI, AI-Assisted,
   AI-Augmented, AI-First, AI-Driven.
   • Ecosistema de IAs actuales para asistencia al
   desarrollo.
   • IAs generalistas: ChatGPT, Claude, Gemini, DeepSeek .
   Casos de uso, capacidades y limitaciones.
   • IAs especializadas en ingeniería: Cursor, Claude Code,
   Copilot. Casos de uso y contextos de aplicación.
   • Arquitectura de modelos LLM y uso basado en tokens.
   • Principios de Prompt Engineering para desarrollo de
   software.
   • Taller: Evaluación y selección estratégica de IAs según
   escenarios y casos de ingeniería propuestos.
   • Taller: Integración de IAs al entorno de desarrollo
   (ejemplo con VSC).
1. Diseño de interfaces potenciado con IA
   • Principios básicos de UX/UI.
   • Componentes y Design Systems.
   • Responsive & Movile Design.
   • Prompt Engineering para diseño.
   • Taller: Exploración de requerimientos funcionales y
   construcción de user flows asistidos por IA (ChatGPT /
   Claude)
   • Taller: Construcción inicial de wireframes orientados a
   experiencia de usuario (Figma AI)
   • Taller: Exploración visual y generación de propuestas
   con enfoque moderno (Claude Design)
   • Taller: Consolidación de la exploración visual y
   construcción del Design System (Figma AI)
1. Implementación de interfaces potenciado
   con IA (AI-Augmented)
   • Arquitecturas modernas para proyectos Frontend:- Component -Based.- Container / Presentational.- Flux/Redux.- MVC/MVVM.- Feature - Sliced Design.- Microfrontends.
   • Taller: Construcción asistida del scaffold inicial del
   proyecto frontend (Claude Code).
   • Taller: Implementación de componentes y código
   frontend para diferentes arquitecturas (Claude Code)
1. IA para refactorización y migración de
   código Frontend
   • Refactorización de código con IA . Ventajas y casos de
   uso.
   • Migraciones de código con IA. Casos de uso y
   precauciones.
   • Taller: Evolución de la arquitectura frontend hacia
   una escalable y /o modular (Claude Code ).
   • Taller: Mitigación de deuda técnica en un proyecto
   frontend legacy.
   II. Backend Engineering potenciado con IA
   (AI-Augmented)
1. Diseño funcional y arquitectura backend
   con IA
   • Arquitecturas modernas para proyectos Backend:- Microservicios.- Modular monolith.- Event -Driven.- Serverless.- API- First.- Layered Architecture
   • Taller: Construcción asistida del scaffold del proyecto
   backend (Claude Code).
   • Taller: Implementación de compone ntes y código
   backend para diferentes arquitecturas (Claude Code).
1. IA para refactorización y migración de
   código Backend
   • Taller: Evolución de la arquitectura backend hacia una
   escalable.
   • Taller: Mitigación de deuda técnica en un proyecto
   backend legacy.
   III. Soluciones software con IA embebida
   (AI-Driven)
1. Fundamentos de LLM
   • Los grandes m odelos de lenguaje (LLM s). Definición
   arquitectura general, casos de uso.
   • Proveedores de LLM, métodos de acceso y modelos de
   costo.
   • Taller: Implementación en el backend de un módulo de
   comunicación con una IA LLM (vía API). Test de uso
   (preguntas y respuestas).
1. NL2SQL
   • Flujo de generación dinámica de SQL mediante lenguaje
   natural.
   • Function calling y ejecución de acciones.
   • Introducción a MCP. Ventajas y casos de uso.
   • Taller: Implementación de NL2SQLService y módulos
   conexos (ChatController, SQLValidator, FuncionsCalling,
   etc.)
   IV. Multi-Agent Software Architecture
   Foundation (AI-First)
1. Introducción a los sistemas multiagente
   • Diseño de arquitecturas multi-agente para desarrollo de
   software.
   • Contexto, memoria y coordinación entre agentes.
   • Orquestación secuencial y jerárquica.
   • Taller: Implementación de un agente para desarrollo
   Frontend, según requerimientos, arquitectura y lenguaje
   especificados (con Claude Code).
   • Taller: Implementación de un agente para desarrollo
   Backend, según requerimientos, arquitectura y lenguaje
   especificados (con Claude Code).
   • Taller: Orquesta ción de los agentes Frontend y E.
