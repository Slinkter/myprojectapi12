## 📁 Estructura de este proyecto

```
myprojectapi12/
├── src/                    ← El código fuente
│   ├── features/           ← Las funcionalidades (productos, carrito, etc.)
│   ├── components/        ← Piezas reutilizables
│   ├── pages/             ← Las páginas que ves
│   └── app/               ← Configuración
├── docs/                  ← La documentación (lo que estás leyendo)
│   └── guides/            ← Las guías de aprendizaje
├── dist/                  ← El proyecto compilado (para producción)
└── package.json           ← Lista de herramientas
```

## 🎯 Misión del proyecto

Este proyecto es una **tienda e-commerce** (tienda online) donde puedes:
- Ver productos
- Agregarlos al carrito
- Buscar productos
- Completar una compra (simulada)
- Cambiar entre tema claro/oscuro

¡Es como una tienda real, pero simplificada para aprender!
