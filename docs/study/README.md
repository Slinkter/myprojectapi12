# Guía de Estudio — React SPA: myprojectapi12

Ruta de aprendizaje completa para dominar los patrones, algoritmos y arquitectura de una SPA moderna de comercio electrónico construida con React 18, TypeScript, Tailwind CSS v4 y TanStack Query.

---

## Ruta de Aprendizaje

```
PRERREQUISITOS
      |
      v
INICIO RÁPIDO ──→ ESTRUCTURA (FSD)
      |                    |
      v                    v
TECNOLOGÍAS ←──────┬──────→ ESTADO GLOBAL
      |                    |
      v                    v
CUSTOM HOOKS ────→ ALGORITMOS
      |                    |
      v                    v
FLUJO DE COMPRA ──→ COMPONENTES UI
      |                    |
      v                    v
ESTILOS ──────────→ API Y DATOS
      |                    |
      v                    v
DESPLIEGUE ───────→ EJERCICIOS
```

## Módulos

| # | Módulo | Descripción | Duración |
|---|--------|-------------|----------|
| 00 | **Prerrequisitos** | Node.js, pnpm, Git, VS Code + extensiones | 15 min |
| 01 | **Inicio Rápido** | Clonar, instalar, ejecutar dev server, build | 10 min |
| 02 | **Estructura (FSD)** | Capas, regla de dependencia, barrel files | 30 min |
| 03 | **Tecnologías** | React 18, TS, Vite, Tailwind v4, TanStack Query, Context, Radix | 45 min |
| 04 | **Algoritmos** | Infinite scroll, merge carrito, reducer checkout, validaciones, debounce | 60 min |
| 05 | **Custom Hooks** | useProducts, useCart, useCheckout, useDebounce, etc. | 45 min |
| 06 | **Estado Global** | Context API vs TanStack Query vs useState vs useReducer | 30 min |
| 07 | **Flujo de Compra** | Home → Modal → Cart → Checkout → Success | 30 min |
| 08 | **Componentes UI** | Composición, compound components, as prop, Radix, Tailwind | 30 min |
| 09 | **Estilos** | Tailwind v4, @theme, @import, dark mode, glassmorphism | 30 min |
| 10 | **API y Datos** | httpClient, mappers, errores, type safety | 30 min |
| 11 | **Despliegue** | CI/CD con GitHub Actions, Pages, lint → type-check → build | 20 min |
| 12 | **Ejercicios** | 15+ ejercicios progresivos BASIC/INTERMEDIATE/ADVANCED | 4-6 h |
| — | **Glosario** | 50+ términos técnicos | Referencia |
