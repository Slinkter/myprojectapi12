## 🔴 Bugs Críticos Corregidos

### BUG-001 — `IProduct` no re-exportado de `cartTypes.ts`
- **Archivo**: `src/features/cart/domain/cartTypes.ts`
- **Error TS**: `TS2459: Module declares 'IProduct' locally, but it is not exported`
- **Causa raíz**: `cartTypes.ts` hacía `import type { IProduct }` desde `productTypes` pero no lo re-exportaba. Cualquier archivo que importara `IProduct` desde `cartTypes` fallaba.
- **Impacto**: 3 archivos, 14 errores TS cascada en tests y hooks.
- **Fix**: Añadir `export type { IProduct }` en `cartTypes.ts`.

### BUG-002 — `HiMiniCircle` no existe en `react-icons/hi2`
- **Archivo**: `src/components/ui/dropdown-menu.tsx`
- **Error TS**: `TS2724: 'react-icons/hi2' has no exported member named 'HiMiniCircle'`
- **Causa raíz**: El ícono fue buscado por su forma esperada pero no existe con ese nombre en la librería.
- **Fix**: Removido el import. Reemplazado con SVG inline `<circle cx="4" cy="4" r="4"/>`.

### BUG-003 — Fixtures de test incompletos (`description` missing)
- **Archivos**: `cartUtils.test.ts`, `CartContext.test.tsx`
- **Error TS**: `TS2741: Property 'description' is missing` (×14 instancias)
- **Causa raíz**: Los objetos de test no incluían `description`, campo requerido en `IProduct`.
- **Fix**: Creada factory `src/test/factories/productFactory.ts` con `makeProduct()` y `makeCartItem()` que generan fixtures válidos con todos los campos. Tests refactorizados para usar la factory.

## 🟡 Bugs de UX/UI Corregidos

### BUG-004 — SearchInput: Focus Ring Rectangular
- **Archivo**: `src/features/products/presentation/components/SearchInput.tsx`
- **Síntoma**: Al hacer click en el input, el ring de foco era rectangular mientras el input era redondeado (`rounded-xl`).
- **Causa raíz**: El `ring-2` se aplicaba al wrapper `<div>` sin `border-radius`. El `rounded-xl` solo existía en el `<input>`.
- **Fix**: Mover `rounded-xl + border + ring` al wrapper. El input queda `bg-transparent` heredando el fondo del wrapper.

### BUG-005 — Tokens de color inexistentes causaban colores invisibles/rotos
- **Archivos**: Navbar, ProductCard, ProductDetailModal, CartIcon button
- **Tokens inválidos usados**:
  - `text-foreground-muted` → TS no se queja (es una string) pero Tailwind no genera ninguna clase CSS → texto invisible.
  - `text-foreground-subtle` → mismo problema.
  - `bg-surface` → Tailwind v4 requiere `--color-surface` en `@theme`. No estaba definida.
- **Fix**: 
  - Todos reemplazados por `text-muted-foreground` (existente).
  - `--color-surface` añadida al `@theme` para modo light y dark.

### BUG-006 — ProductCard Footer desalineado
- **Archivo**: `src/features/products/presentation/ProductCard.tsx`
- **Síntoma**: Precio (2 líneas) y botón (1 línea) se alineaban por el centro vertical → desajuste visual.
- **Causa raíz**: `items-center` + `mt-auto` redundante. El `m.div` wrapper del grid no tenía `h-full`.
- **Fix**:
  - Footer: `items-end` + `self-end` en botón + `pt-4` para respiración del borde.
  - Grid: `items-stretch` + `h-full` en cada `m.div`.

### BUG-007 — Toast messages en inglés (inconsistencia de idioma)
- **Archivo**: `src/features/cart/application/hooks/useCartActions.ts`
- **Síntoma**: La UI es completamente en español, pero los mensajes de "Product removed" y "cart emptied" eran en inglés.
- **Fix**: Traducidos a español. Assertions de test actualizadas en consecuencia.

## 🟢 Mejoras / Refactorizaciones

### REFACTOR-001 — HomeHeader: div manuales → Button component
- Los CTAs del hero usaban `<div className="...">` con clases de botón escritas a mano.
- Reemplazados con `<Button>` y `<Button variant="outline">`.
- **Beneficio**: Accesibilidad (focus ring, keyboard nav), consistencia con las cards.

### REFACTOR-002 — Test Factory Pattern
- Creada `src/test/factories/productFactory.ts`.
- `cartUtils.test.ts` reducido de 281 a 131 líneas (53% menos).
- Eliminación de 14 objetos literales duplicados e incompletos.

### REFACTOR-003 — dark .glass-card selector
- El selector `.dark .glass-card` usaba `bg-slate-950/60` hardcodeado.
- Actualizado a `bg-card/60 border-border/40` para seguir el sistema semántico.

### REFACTOR-004 — Sincronización gap en SkeletonGrid
- `SkeletonGrid` tenía `gap-8`, `ProductGrid` tenía `gap-6`.
- Causaba layout shift visible al cargar. Unificados a `gap-6`.
